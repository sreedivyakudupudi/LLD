# [RPG Character Creation System ](https://github.com/sreedivyakudupudi/LLD/tree/parking/RolePlayingGame)

A Python-based RPG Character Creation System demonstrating object-oriented programming and design patterns, particularly the **Builder** and **Prototype** patterns.

### Features
- Create different character types: Warrior, Mage, and Archer.
- Use the Builder Pattern to construct characters.
- Use the Prototype Pattern to clone predefined character templates.
- Maintain a Character Registry to manage prototypes.
- Manage characters through a Character Manager.
- Implement inventory management with support for adding, removing, updating, and viewing items.
- Ensure cloned characters have unique IDs and independent weapons, skills, and inventories.
- Include input validation and error handling.

### Technologies
- Python
- Object-Oriented Programming
- Builder Design Pattern
- Prototype Design Pattern
